# Settings

Every name a settings loader reads from the environment: its default in the code (or `unset` when optional, `required` when the loader refuses to start without it) and what it tunes. Generated by `scripts/settings-table.ts` from the loaders: do not edit it by hand. After a loader changes, run `bun scripts/settings-table.ts --write`; make docs-check fails until it does. Prose names a setting by linking here.
