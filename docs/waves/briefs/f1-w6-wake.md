F1 Wave 6's retirement (FL8, `docs/decisions.md`) removes `wave-watch.sh`, the poll loop an orchestrator (a lead, a mother, an orchestrated wave's spawner) uses today to block until its workers finish. The factory has the other half already: a session declares `factory session wait --on workers` (state `waiting`), and send-back (FL5) holds its Stop while children run. What is missing is the wake-up: nothing tells a waiting session that its workers are done, so with `wave-watch.sh` gone an orchestrator that ends its turn would never resume. Read `AGENTS.md` (the rules list, "Facts are stored, state is derived", "Every effect has a deterministic key"), `docs/design.md` §3 and `packages/server/src/rules.ts` (`blockedParents` and `rotation` are the closest patterns) first.

The rule, **Wake**: a session whose open wait is `--on workers`, that has at least one child session (sessions of spawns whose `parent` is it), and none of whose children is still unfinished, gets one note: the children's keys with their derived state, e.g. `workers done: usage-tracker-w4 idle, dotfiles-x dead`. A child counts as finished when it is `dead`, or `idle` after a turn that ended in its current life (the same definition `liveSessions` uses for `finished` since PR #8, `sessions.ts`; reuse it, do not write a second one). A child that is `walled`, `blocked`, `working`, `starting` or `waiting` is not finished. Key `wake:<session>:<the wait's declared event key>`, so one note per declared wait, and a new wait after the wake can wake again. A parent that is not `waiting` gets nothing (send-back already covers a working parent). A child queued but not started (a spawn row with no session yet, held or waiting for capacity) is not finished either: read the spawns too.

Tests through the public surface the other rules use (`evaluateRules` with the fake herdr and a private Postgres): no note while one child works; one note when the last one finishes; none twice for the same wait; none for a held spawn; a second wait after the wake wakes again; a parent that is not waiting gets none.
